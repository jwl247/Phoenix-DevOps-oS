## What is Phoenix?

Phoenix is a 100-point versioned operating system with a click, clone, and
drag-and-drop file tree interface. It was built from the ground up after vendor
lock-in threatened a project built for someone who needed it. That's when
"nice to have" became "non-negotiable."

At its core is **Helix** — and there is only one.

---

## Helix — The Engine

Helix is a true Double Helix twin single-pass memory manager. It is the foundation
everything in Phoenix is built on.

| Metric | Value |
|--------|-------|
| Throughput | 700,000 ops/sec |
| Cache hit rate | 100% |
| Languages | 4 simultaneously |
| Compression | zlib level 5 |
| RAM (thermal limited) | 4GB of 8GB |
| Architecture | Twin single-pass, peer-optimized |

Helix speaks 4 languages simultaneously. She was built to self-host
[Life First App](https://github.com/jwl247/LifeFirstApp) after vendor lock-in
made it a necessity rather than a choice.

## Features

- **Agnostic** — works regardless of your stack or environment
- **Deterministic** — predictable, repeatable behavior every time
- **Prefetched** — data where you need it, before you need it
- **Self-healing** — 100-point versioned system monitors and recovers automatically
- **Click, clone, drag-and-drop** — file tree interface anyone can use
- **Phoenix Package Handler** — unifies everything under one roof
- **REALsure Security** — architecture and AI modules combined for hardened security
- **Double Helix StorageOS** — benchmarked against AWS S3 at 97,000 ops/sec
- **Installer Guardian** — monitors ports, config files, and file movement

## Getting Started

### Requirements
- Python 3.10 or higher
- Git
- 2GB RAM minimum (4GB recommended)
- Linux (Ubuntu 20.04+ recommended) or compatible environment

### Installation

```bash
# Clone the repository
git clone https://github.com/jwl247/Phoenix-DevOps-oS.git

# Navigate into the directory
cd Phoenix-DevOps-oS

# Run the installer
python installer.py
```

> For detailed self-hosting instructions, see [INSTALL.md](INSTALL.md)
