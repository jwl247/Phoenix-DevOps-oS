# Graphic design basics

## The four principles (contrast, repetition, alignment, proximity)
Contrast: make different things really different (big vs small, dark vs light, bold vs thin) so the eye knows what matters. Repetition: reuse the same colors, fonts and shapes so a design feels like one piece. Alignment: line every element up with something else; nothing placed at random. Proximity: put related things close together and unrelated things apart; space itself groups information.

## Visual hierarchy (what gets seen first)
Decide the one thing a viewer must see first, the second, and the third. Make the first biggest, boldest or brightest. Use size, weight, color and position (top-left reads first in English). If everything shouts, nothing is heard.

## Typography
Use at most two typefaces: one for headings, one for body text. Body text for screens: 14 to 18 pixels, line length 45 to 75 characters, line spacing about 1.4 to 1.6. Sans-serif fonts read better on screens at small sizes. Never use all-caps for long text. Make sure text contrast is high (dark on light or light on dark).

## Color for screens and print
Screens use RGB (hex codes like #F4C2C2); print uses CMYK, so printed colors can look duller than on screen: always print a test. Pick a palette of 3 to 5 colors: a main brand color, a darker and lighter version of it, a neutral, and one accent. Check text contrast: a ratio of at least 4.5 to 1 for normal text is the accessibility standard (WCAG AA).

## Logos and icons
A good logo works in one color, works tiny (16 pixels, a browser tab) and big (a sign), and is recognizable from its silhouette alone. Icons in one set should share the same stroke width, corner style and grid size. Save logos and icons as SVG (vector) so they stay sharp at any size; export PNG for places that need images.

## Layout and grids
Use a grid (12 columns is common for web and screens) and consistent margins. Leave white space: crowded designs look cheap and are hard to read. Group related items in cards or boxes. Keep buttons the same style everywhere.

## File formats
SVG: logos, icons, line art (scales forever). PNG: graphics with transparency or sharp edges. JPG: photos (small files, no transparency). WebP: smaller web images. PDF: print and documents. Keep the original layered source file (for example .psd, .kra, .xcf, .afdesign) separately.
