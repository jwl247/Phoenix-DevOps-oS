## 5. Gotchas learned today
- Bash heredocs here eat `\\` and `\n` in Python strings — write patch scripts with the Write tool (bit me 3 times today).
- Windows hands a child EVERY inheritable handle under CreateProcess: start long-lived processes with ShellExecute (Start-Process, no redirect) or they hold a caller's pipe open forever.
- A pythonw service starting a console program (sc, netsh…) without CREATE_NO_WINDOW opens a Windows Terminal window (default terminal) — that was the flashing.
- A non-elevated task can't read the Path of an elevated process: identify by port owner/name, not Path.
- `usys.cmd` strips JSON quotes from arguments — usys import now wraps words into the stage.
