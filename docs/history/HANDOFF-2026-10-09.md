## 5. Gotchas learned
- `Write-Error` in a `-File` script prints a dump and exits 0 → use a stderr line + a failure flag + `exit 1`.
- In cmd, `%ERRORLEVEL%` inside a `( )` block is read before the call runs; and `cmd /c "x & echo %ERRORLEVEL%"` expands at parse time — measure exit codes from PowerShell's `$LASTEXITCODE`.
- PowerShell aliases beat functions: `start` needed `Remove-Item alias:start` before a `start` function could win.
- `genie log` takes `-Lines` by name; an array splat passes "2000" positionally and silently gives 40 lines.
- Python `-I` ignores PYTHON* env vars: use `sys.stdout.reconfigure(encoding="utf-8")`.
- Sed on a CRLF file rewrites every line ending (a 248-line diff for a 1-line change) — edit bytes in Python.
- Claude Code auto mode can switch off mid-session: then ask before each change.
